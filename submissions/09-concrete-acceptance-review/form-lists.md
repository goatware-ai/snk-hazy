# Form lists

Entries for the platform form, written from the zip listings. Each Input File List entry is the exact file name, a plain hyphen, then what it contains.

## Input File List

- cylinder_breaks_2417.csv - the laboratory's 28-day cylinder break file for the period, one line per cylinder, with set, placement, cast and test dates, age, diameter and length, maximum load, technician and fracture type
- placement_log_2417.csv - the placement log with each placement's date, element, mix, cubic yards, slump, air content and concrete temperature
- spec_033000_excerpt.docx - the project specification excerpt for cast-in-place concrete: mixtures and limits, sampling frequency, what makes a strength test, age tolerance, range and curing notes, the acceptance criteria and what follows a failing test, and the reporting form
- lab_procedure_lp07_c39.docx - the laboratory's compressive strength procedure: specimen sizes and test ages, area and strength computation and rounding, within-test range, fracture types and reporting
- lab_quality_memo_2417.docx - the laboratory manager's memo on the events of the period that bear on the tests, and what the acceptance summary needs to carry

## Output File List

- acceptance_summary_2417_aug_sep.xlsx - the acceptance summary workbook with the engineer's page, the cylinder strengths, the strength tests with moving averages in casting order, the sampling check by placement and the note to the laboratory manager
