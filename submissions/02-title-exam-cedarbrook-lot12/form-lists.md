# Form lists

Entries for the platform form, written from the zip listings. Each Input File List entry is the exact file name, a plain hyphen, then what it contains.

## Input File List

- recorder_index_cedarbrook_lot12.csv - Licking County recorder's index entries for the parcel by name and legal description, 1986 through the October 2, 2026 search date: instrument number, recording date, document type, parties, volume and page, amount, legal description, and referenced instrument
- instrument_abstracts_hlt262214.docx - the searcher's abstracts of the recorded instruments that matter, with parties, marital recitals, legal descriptions as written, signatures, and release references, plus the searcher's notes
- title_order_hlt262214.docx - the closing agent's title order and closing instructions for order HLT-26-2214, with the parties, price, lender, closing date, proration instructions, and the underwriter's examination guideline excerpts
- tax_and_lien_search_hlt262214.xlsx - the treasurer's tax duplicate inquiry for the parcel, the clerk of courts judgment lien search results, and the names searched with the period each held an interest

## Output File List

- title_exam_report_cedarbrook_lot12.docx - the title examination report to the closing agent with vesting, chain of title, requirements, exceptions, closing figures, and open matters
